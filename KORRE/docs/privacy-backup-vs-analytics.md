# Privacidade: Backup vs Analytics

## Backup online (privado)
- finalidade: recuperação de dados do próprio usuário
- dados: conjunto completo funcional do app (sem senha/hash)
- acesso: apenas usuário autenticado
- consentimento: `online_backup`

## Analytics anônimo/agregado
- finalidade: estatísticas e relatórios de mercado
- dados: agregados, sem reidentificação
- consentimento: `anonymous_analytics`

## Regra de ouro
Nunca misturar backup privado com analytics comercial.
