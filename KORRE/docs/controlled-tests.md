# Programa de Testes Controlados

## Objetivo
Coletar apenas diagnóstico técnico para validar atualizações sem expor dados pessoais.

## Consentimento
- chave: `controlled_tests_diagnostics`
- padrão: desativado

## Dados permitidos
- versão do app
- versão do banco
- status de migração
- status de backup
- contagem de registros por tabela

## Dados proibidos
- dados brutos de usuário
- CPF, nome, e-mail, placa, senha/hash
